# 鹿大じかんわり

鹿児島大学の学生のための時間割アプリです。**シラバスのページから、ボタン1つで授業を時間割に入れられます。** 入れた授業からは、いつでもすぐにその授業のシラバスへ戻れます。

アカウントもサーバーも要りません。データは端末のブラウザの中だけに保存され、一度開けば電波のない教室でも見られます（PWA。スマホでは「ホーム画面に追加」でアプリのように使えます）。

## 鹿大向けにしてあるところ

- **授業時間**：鹿大の標準（1限 8:50〜10:20 / 2限 10:30〜12:00 / 3限 12:50〜14:20 / 4限 14:30〜16:00 / 5限 16:10〜17:40）。6限や、学部で違う時間は設定で直せます
- **年度・前期/後期**：4〜9月は前期、10〜3月は後期を最初に開きます（1〜3月は前の年度）。通年の授業は両方に出ます
- **シラバス**：
  - 上の「🔎 シラバス検索」で [鹿児島大学シラバス検索](https://syllabus11.kuas.kagoshima-u.ac.jp/showSearch) を開けます
  - 授業ごとにシラバスのURLを持ち、授業を開くと「📖 シラバスを開く」が一番大きなボタンで出ます
  - URLが未登録の授業は「シラバス検索で探す」で、時間割コード（なければ科目名）をコピーしてから検索画面を開きます
- **学務系ポータル**・**manaba**（設定でURLを入れると出ます）へのリンク
- **時間割コード**を授業ごとに持ち、タップでコピーできます（履修登録のときに便利）

## シラバスから授業を追加する

### パソコン：ブックマークレット（1回で追加）

1. 設定（⚙）を開き、「＋時間割に追加」ボタンをブックマークバーにドラッグする
2. シラバス検索で授業の詳しいページを開き、ブックマークの「＋時間割に追加」を押す
3. このアプリが開き、科目名・担当教員・教室・曜日時限・時間割コード・単位・学期・シラバスのURLが入った状態になるので、確かめて保存

### スマホ

- **貼り付け**：シラバスのページで全体を選んでコピー →「＋」→「📋 シラバスから読み込む」に貼り付けて「読み取る」
- **ブックマークレット**：設定の「コードをコピー」で写し、適当なページをブックマークしてから、そのURLを貼り付けたコードに書き換える（iPhone の Safari でも動きます）
- **共有**（Android でホーム画面に追加したとき）：シラバスのページを共有 → 鹿大じかんわり で、そのURLが入った状態で開きます

鹿大シラバス検索（syllabus11）の授業のページでは、ブックマークレットがページに埋め込まれたデータをそのまま読むので、科目名・担当教員・単位・学期・曜日時限・授業回数が正確に入ります（教室はシラバスに載っていないので手で入れてください）。体育のように「月 火 水 木」「1限〜4限」と書かれていて組み合わせが分からない授業は、曜日・時限を選んでもらうようにしています。

読み取りは `parse.js` で行っています。「曜日・時限」は `月1` `水曜日 3時限` `金3-4` `月曜3・4時限` `火1,木1` などの書き方に対応し、2コマ続きの授業や週2回の授業もまとめて入ります。

## 「＋」でそのコマの授業から選ぶ

時間割の空いたコマの「＋」を押すと、そのコマに開講されている授業の一覧が出ます。「＋ 追加」を押すだけで時間割（そのコマに授業があれば候補）に入ります。

- 学部・学年を選ぶと、共通教育とその学部の授業に絞り込めます（選んだ学部・学年は覚えておきます）。科目名や先生の名前でもさがせます
- 「📖 シラバス」でその授業のシラバスを開けます
- 一覧には単位数がないので、単位を入れたいときは、その授業のシラバスを開いてブックマークレットを押すと、空いている項目（単位・授業回数など）が埋まります
- 「月 火 水 木」「1限〜4限」のように組み合わせが分からない授業は、押したコマだけに入ります

一覧は `data/syllabus-<年度>.json` にあり、[鹿児島大学シラバス検索](https://syllabus11.kuas.kagoshima-u.ac.jp/showSearch) の検索結果を `scripts/fetch-syllabus.mjs` で集めたものです（科目名・担当教員・開設部局・学期・曜日・時限・学年・シラバスの番号だけ）。GitHub Actions（`.github/workflows/syllabus.yml`）が毎週月曜の朝に取り直し、変わっていれば公開し直します。相手のサーバーに負担をかけないよう、1年度あたり10回ほどの問い合わせを間をあけて行います。Actions の画面から「シラバスの授業一覧を更新」を手動で実行することもできます。

## 同じコマの候補をくらべて決める

履修登録の前は、同じ時間に気になる授業がいくつもあるはずです。授業ごとに「履修する」か「候補」かを持てます。

- 候補だけのコマは点線の枠で「候補3」と名前が出ます。履修する授業があるコマには「ほか候補1」と出ます
- タップすると、そのコマの授業と候補が並び、それぞれのシラバスを開いて比べられます
- 「これにする」で決めると、同じコマで履修中だった授業は候補にもどり、ほかの候補を「消す」か「候補のまま残す」か選べます
- 候補は単位の合計・コマ数・「いま・つぎ」に入りません
- シラバスから追加するとき、そのコマにもう履修する授業があれば、最初から候補として入ります

## そのほかの機能

- 今の授業・次の授業（教室と残り時間）を一番上に表示。今のコマを時間割の中でも強調
- 欠席回数のカウンター（授業回数の3分の1を目安に、近づくと警告。正式な条件は授業ごとにシラバスで確認してください）
- 課題・提出物（期限つき。期限が近い順に一覧）
- 集中講義・時間外の授業の一覧
- 単位数の合計（学期・年度・区分ごと）、週のコマ数
- 時間が重なっている授業の表示
- ダークモード、データの書き出し・読み込み（機種変更用）

## 動かし方

ビルドは要りません。静的ファイルをそのまま置くだけです。

```sh
npm run serve      # http://localhost:4173/
npm test           # シラバス読み取りのテスト
node scripts/fetch-syllabus.mjs   # 授業の一覧を取り直す（data/ に書く）
```

`main` に入ると GitHub Actions で GitHub Pages に公開します（リポジトリの Settings → Pages → Source を「GitHub Actions」にしておいてください）。

## 注意

- 鹿児島大学の公式アプリではありません
- シラバスの画面の作りが変わると、読み取れない項目が出ることがあります。そのときは `parse.js` の `LABELS` に見出しの言葉を足してください
